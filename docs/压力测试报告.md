# 复杂文档压力测试报告

测试版本：1.2.0  
测试日期：2026-09-24

## 覆盖场景

压力测试程序会动态生成合法的 DOCX 包，再调用与桌面程序相同的比较核心：

- 约 15.8 万字符：700 段中英混排正文、45×7 表格、嵌套表格、文本框、页眉、页脚、脚注和尾注；包含货币、数学符号、方向符号、引号与 Emoji。
- 约 40.3 万字符：1800 段正文及约 1 万字符的超长单段，验证大文档路径及超大差异的降级算法。
- 约 13.5 万字符：620 个基准段落，按固定间隔删除整段并插入新段落，验证删除内容写回、删除线与位置对齐。
- 约 20.5 万字符：950 段文字完全相同，但运行拆分、颜色和粗体不同，验证排版/格式变化不会误报。

## 测试结果

完整压力测试连续执行 3 轮，共 12 个复杂场景，全部通过；另执行 5 项基础回归测试，全部通过。

| 场景 | 结果 | 单次核心耗时范围 |
|---|---:|---:|
| 混合语言、符号及全部文字部件 | 通过 | 204–225 ms |
| 1800 段及超长段落 | 通过 | 141–165 ms |
| 大量整段删除及新增 | 通过；识别 89 个删除段落 | 63–89 ms |
| 950 段纯格式噪声 | 通过；0 个误报 | 67–79 ms |

耗时为当前测试机器的比较核心实测值，不含用户选择文件及 Word 打开文件的时间，不作为其他机器的性能承诺。

## 完整性检查

- 每个输出文件均可作为 ZIP/OOXML 包重新打开。
- 输出内全部 XML 部件均使用禁用 DTD 和外部解析器的解析器重新读取成功。
- 校验正文、页眉和其他文字部件中的高亮颜色。
- 校验旧版删除内容、`w:strike` 删除线及删除统计。
- 校验纯格式场景输出正文与新版本正文逐字节一致。
- 校验应用源码和构建脚本不引用 HTTP 客户端、套接字或下载 API。

自动化脚本：`stress-test.ps1`。运行时会在 `artifacts/stress-run` 生成旧版、新版及差异输出样本。

说明：当前构建环境未提供 LibreOffice，因此自动 DOCX 转 PNG 视觉渲染步骤不可用；本轮采用 OOXML 包结构、全部 XML 可解析性、内容与标注语义断言进行验证。桌面界面和嵌入图标已另行渲染检查。
