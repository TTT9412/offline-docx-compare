# 离线文档对比

一个完全本地运行的 Windows 桌面工具，用来比较两个 `.docx` 文档的纯文字差异，并在新版本副本中用所选颜色高亮变化文字。

## 功能

- 对比正文、表格、嵌套表格、页眉、页脚、脚注、尾注和文本框中的文字
- 忽略字体、字号、文字颜色、背景颜色、段落样式和页面排版差异
- 在新版本文档副本中进行词级高亮，不改写原始文件
- 段落内被删除或替换掉的旧文字会在原位置附近显示为“旧版删除”红色删除线
- 整段被删除的旧内容会按原顺序插回副本并显示为红色删除线
- 支持黄色、蓝色、绿色、青色、粉色、红色和浅灰色
- 支持文件选择、拖放、后台处理、进度显示和结果统计
- 不调用网络、不上传文件、无遥测、无更新检查、无账号体系
- 不依赖 Microsoft Word，不使用 Office COM 自动化
- 内置专属应用图标，便于在桌面、任务栏和资源管理器中识别

## 运行

直接双击：

`dist\离线文档对比.exe`

系统要求：Windows 10 或 Windows 11，.NET Framework 4.8。

## 使用方法

1. 选择或拖入旧版本 `.docx`。
2. 选择或拖入新版本 `.docx`。
3. 选择高亮颜色和输出位置。
4. 点击“开始对比并生成文档”。

快捷键：

- `Ctrl+O`：选择旧版本
- `Ctrl+Shift+O`：选择新版本
- `Ctrl+R`：开始对比

## 标注规则

- 新版本新增或替换后的文字：使用用户选择的 Word 高亮色。
- 旧版本中被删除或替换掉的文字：以“旧版删除”标记、红色文字、删除线和浅灰底显示。
- 整段删除：在新副本的对应位置附近插入删除标记段落。

## 本地构建

项目不需要下载 NuGet 包，使用 Windows 自带的 .NET Framework 编译器：

```powershell
.\build.ps1
```

构建并运行测试：

```powershell
.\build.ps1 -RunTests
```

运行包含 10 万至 40 万字符、多语言、Unicode 符号、复杂表格及大量删除的压力测试：

```powershell
.\stress-test.ps1
```

## 实现原则

- 输出以新版本 DOCX 包为基础，只修改包含文字的 OOXML 部件。
- 高亮通过标准 `w:highlight` 写入，并保留新版本已有的段落、表格和字符格式。
- XML 解析禁用 DTD 和外部解析器，且限制单个文字部件的解压大小。
- 输出先写入临时文件，完成后再替换目标文件，避免中途中断留下损坏文档。
